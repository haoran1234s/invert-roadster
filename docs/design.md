# 《倒悬极速 / INVERT》3D 飞车游戏设计文档（v0.1）
> 灵感来自 2026-10-15 新一代 Roadster 发布演示。公开发布请勿使用 Tesla/Roadster/SpaceX 名称与标志，车型改为“致敬款”造型（暂名 Volt Roadster / 零号跑车）。

## 1. 概念
夜间秘密试验场，驾驶带吸地风扇+冷气推进器的电动超跑：冲上越过垂直的巨型弯道、倒挂行驶、离坡后用推进器悬停/调姿、在蒸汽中精准落地。核心卖点：可玩（易上手、有技巧上限）+ 表演（自动电影镜头回放）+ 可扩展（数据驱动）。
备选名：倒悬极速 / 零点八秒 / 吸地者 / Downforce / Flying Cars Are Real

## 2. 核心循环
起跑加速 → 上弯道（吸地保持贴附）→ 倒挂/翻越 → 离坡腾空 → 推进器调姿悬停 → 落地评分 → 解锁新场地/涂装/推进器配置 → 再挑战。

## 3. 操作
| 动作 | 键盘 | 手柄 |
|---|---|---|
| 油门/刹车倒车 | W / S | RT / LT |
| 转向 | A / D | 左摇杆 |
| 吸地风扇（加大下压力，耗电） | Shift | RB |
| 推进器上推/悬停 | Space | A |
| 空中俯仰/横滚/偏航 | ↑↓ ←→ / Q E | 右摇杆 / LB+摇杆 |
| 推进器点射前冲 | F | X |
| 切镜头 / 回放 | C / R | Y / Back |
| 重置到检查点 | Backspace | Start 长按 |

## 4. 物理模型（街机向）
- 刚体车 + 射线悬挂（Rapier raycast vehicle 或自写 4 射线）。
- 贴附：每个车轮射线命中表面时，沿表面法线施加“下压力” F = k·v² + 风扇常量（风扇让 0 速也能吸住，对应发布会“静止倒挂”宣传）。若 F > 车重沿法线分量 → 保持贴附，可在墙/天花板行驶。
- 重力方向保持世界向下，但转向/抓地按表面坐标系计算；脱离判定有 0.2s 宽容时间。
- 推进器：资源条（气罐 100%），上推/俯仰/横滚扭矩，空中缓慢回充，落地快速回充；耗尽时只能滑翔下落。
- 辅助：空中自动姿态稳定（可关）、落地吸附修正；难度档控制宽容度。
- 参数全部外置到 vehicle JSON。

## 5. 模式
1. 特技场：限时内刷分，倒挂、腾空、翻转、推进器救车。
2. 时间赛：检查点圈速赛，幽灵车。
3. 自由模式：无限气罐，沙盒试验场。
4. 表演/回放：录制输入与状态，自动导演镜头——侧面大全景、无人机跟拍、俯视、慢动作、落地蒸汽特写；可导出视频（MediaRecorder）。
5. （扩展）任务挑战：“倒挂过卡车”“悬停 5 秒”等。

## 6. 计分/连击
倒挂时间（每秒 100，越久越高倍率）、腾空时间、翻转 360°、推进器救车（濒坠时挽回 +500）、完美落地（角度<5°、速度合适 ×1.5）、贴墙擦边。连击窗口 3s，倍率最高 ×8，落地失败清零。评级 C~S。

## 7. HUD（复刻视频风格）
线框圆形仪表：DOWNFORCE（KG）、G-FORCE、PITCH（DEG）、ALTITUDE（FT），线框小车图标显示姿态；左上角“LIVE”水印风格的模式标签（换为自有品牌）。另加气罐条、连击分数、速度。

## 8. 视觉/音效
VFX：推进器白色冷气射流（粒子+体积锥）、落地蒸汽云、轮胎烟、红色霓虹弯道边灯、跑道红灯阵列、夜间泛光/雾、慢动作动态模糊、Bloom。
音效：电机高频啸叫（随转速变调）、推进器轰鸣、风扇吸力声、落地冲击、观众/对讲台词（“It worked”“Flying cars are real” 类自制台词）。无背景音乐可选。

## 9. 关卡
1. 夜间试验场（首发：巨型倒悬弯道+红灯跑道+塔台+机库）
2. 沙漠发射场 3. 雨夜城市高架 4. 环形隧道（全程倒挂）5. 太空港/低重力
关卡用编辑器拼装模块（弯道段、跑道、坡道、障碍）。

## 10. 可扩展架构
```
src/
  core/      (loop, input, time, events)
  physics/   (rapier world, vehicle, downforce, thrusters)
  game/      (modes, scoring, checkpoints, replay recorder)
  camera/    (chase, drone, top, cinematic director)
  render/    (scene, post fx, particles)
  ui/        (hud gauges svg/canvas, menus)
  data/      vehicles/*.json  tracks/*.json  thrusters/*.json  modes/*.json
assets/ models(glb+draco) textures(ktx2/webp) audio
```
- 车辆 JSON：质量、扭矩曲线、抓地、下压系数、风扇吸力、推进器列表（位置/方向/推力/气耗）。
- 推进器配置三档：Performance（无推进器）/Thrust（尾部）/Rocket（周身，可飞）——对应公开三配置思路，改名使用。
- 赛道 JSON：模块列表+变换、检查点、灯光、镜头点位。

## 11. 技术栈
Vite + TypeScript + Three.js + Rapier（@dimforge/rapier3d-compat）+ GLTFLoader/DRACOLoader + postprocessing；浏览器运行，后期可 Electron 打包 PC。

## 14. 世界与地形方案
### 14.1 混元世界模型评估（2026-10 核实）
| 版本 | 输出 | 说明 |
|---|---|---|
| HunyuanWorld 1.0（2025-07） | 360° 全景图 + 语义分层 3D 网格（可导出，支持 Draco） | 全景当“世界代理”，前景物体可分离；开源，Tencent Hunyuan 社区许可（不适用欧盟/英国/韩国；月活>100 万需另行授权） |
| Voyager（2025-09） | 按相机轨迹生成 RGB-D 视频，可导出点云 PLY | 适合做过场/参考，不适合游戏碰撞 |
| WorldMirror / 1.1（2025-10）、FlashWorld（2025-10） | 视频/多视图→点云、深度、3DGS | FlashWorld 单卡 5~10 秒出 3DGS |
| 1.5 WorldPlay（2025-12） | 实时交互视频世界 | 像素视频，不能直接导入 |
| HY-World 2.0（2026-04） | 文本/单图→3DGS 世界 + 网格（3DGS→TSDF→Marching Cubes）；gaussians.ply / points.ply | 全部权重开源，有 Gradio 演示；官方称可导入 Blender/Unity/UE |

- 使用方式：网页端在混元 3D 官网体验（https://3d-models.hunyuan.tencent.com/world/）；本地需要高端 NVIDIA 大显存 GPU（估计 24GB 级以上，以官方 README 为准），我们的 box 无 GPU，建议用网页版或云 GPU。
- 导入 Three.js：全景图 → 等距柱状贴图做 skybox/环境光 ✅；网格 → 转 glb（Blender）✅；3DGS .ply → 需第三方 splat 渲染器（如 @mkkellogg/gaussian-splats-3d / Spark），性能吃紧、⚠️。
- 碰撞：生成网格有噪声、孔洞、尺度不准，**不适合当可驾驶表面**；只能做远景/装饰，碰撞用我们自己的简化体。
- 质量局限：远处细节糊、几何漂浮、夜景/霓虹一致性一般、单场景范围有限、无法精确控制坡道尺寸。

### 14.2 结论：分工
- 用混元世界：天空盒/360 全景远景（夜空、沙漠、城市天际线）、IBL 环境光、远景山体/建筑剪影网格（无碰撞）、概念参考。
- 用混元 3D（物体）：车辆、坡道外观、塔台、机库、灯具等可复用道具。
- 自己程序化：所有可驾驶地形与赛道几何、碰撞体、检查点。

### 14.3 地形实现
- 高度图地形：simplex/FBM 噪声 + 手绘遮罩（跑道/坡道区域强制压平），每块 256×256 m，65×65 或 129×129 顶点。
- 碰撞：Rapier `heightfield` 碰撞体，每块一个；坡道/弯道/环形用模块化网格（手工曲线挤出生成，碰撞用凸分解或 trimesh）。
- 分块+LOD：以车辆为中心加载 3×3 块，远处块用低分辨率网格（CDLOD/几何裂缝裙边），超远处只用全景天空盒+混元远景网格。
- 材质：splat map 混合 3~4 层贴图（沥青/混凝土/沙/草），夜间关卡加贴花灯光。
- 生物群落：夜间试验场（平坦混凝土+荒地）、沙漠发射场（沙丘噪声）、雨夜城市高架（无地形，模块化道路）、峡谷（深切高度图，适合大跳）、雪山（缓坡+冰面低摩擦）、太空港/低重力（陨坑噪声）。

### 15.2 推荐融合
Trackmania 的「短关卡 + 秒重开 + 检查点 + 幽灵 + 奖牌」骨架 × Rocket League 的「推进器空中操控」 × Riders Republic 的「连招计分与落地评级」 × Hot Wheels 的「倒挂/环形轨道」 × Burnout 的「擦边慢动作」，单局 30~90 秒，每关 3 星（完成/分数/特殊目标），星数解锁新关卡、涂装、推进器配置；后期开放编辑器 UGC。
新增元素：加速环（穿过回充气罐+加速）、磁吸段（强制贴附）、检查点重生、近距擦边慢动作。
