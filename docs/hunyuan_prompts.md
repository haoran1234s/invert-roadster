# 混元3D 提示词
通用：车身用 500k 生成后我再减面；道具 50k–300k 即可。能分开生成的部件尽量单独生成（车轮、推进器盖板、车顶），便于做动画。纯白背景、无地面、无阴影参考图效果最好。

## 1. 车身（不含车轮）
低趴双门电动超跑，流线型楔形车身，银色金属漆，整块连续黑色玻璃车顶从风挡一直延伸到车尾，车尾一条贯穿式细红色尾灯带，前脸无格栅、细长 LED 大灯，车身侧面平滑无门把手，轮拱空着（不含车轮），车头两侧和车尾下方各有隐藏式小圆形推进器喷口（共约 8 个，四角+侧裙），车底平整带吸气风扇格栅，写实汽车渲染质感，干净拓扑，对称。
- 面数 500k；生成后车轮、玻璃顶、推进器盖板要拆分或单独生成。

## 2. 车轮（单个，生成后复制 4 个）
超跑轮毂+低扁平比轮胎，单个车轮正侧面，黑色多辐空气动力轮毂（近乎封闭的涡轮盖），橡胶轮胎带细胎纹，居中、轴对称。面数 100k。

## 3. 推进器喷口盖板（可选单独件）
小型圆形冷气推进器喷嘴，金属环+可开合的四瓣盖板，银灰色，科幻但写实。面数 30k。

## 4. 可拆卸玻璃车顶（可选）
跑车黑色弧形玻璃车顶单件，单曲面带细边框，与车身同宽。面数 30k。

## 5. 巨型倒悬弯道
巨型混凝土+钢结构特技坡道，从地面平缓起坡，逐渐弯曲超过垂直，在顶部形成向外伸出的倒悬顶棚（像四分之三个管道），弯道两侧边缘装红色霓虹灯带，背面是钢桁架支撑结构，表面光滑灰色，工业试验场风格。面数 200k。
- 提示：车辆行驶面要光滑连续；游戏里碰撞体我会用简化曲面替代，可视模型可稍粗糙。

## 6. 跑道灯模块
机场跑道边灯单元，一段 10 米跑道沥青板，两侧各一排红色嵌入式地灯，白色虚线标线，可无缝拼接。面数 50k。

## 7. 控制塔 / 机库
夜间试验场控制塔，三层混凝土塔身，顶部环形玻璃观察室，天线和雷达，旁边一座半圆拱形大机库，大门半开，工业风，金属质感。面数 300k（塔和机库可分别生成）。

需单独建模用于动画：4 个车轮、推进器盖板、玻璃车顶（开合）、机库大门（可选）。

# 混元世界模型提示词（用于天空盒 / 远景，非可驾驶地面）
使用：网页版生成 360° 全景/世界 → 我导出全景图做 skybox、网格转 glb 做远景（不加碰撞）。避免在画面中心放道路或坡道（这些我们自己建）。

1. 夜间试验场：夜晚荒原上的秘密汽车测试基地，远处有控制塔、机库和探照灯，地平线红色跑道灯延伸，晴朗星空，淡淡雾气，冷蓝色与红色灯光，写实电影感，360 度全景。
2. 沙漠发射场：黄昏沙漠中的火箭发射场，远处发射塔和储罐，起伏沙丘，橙紫色天空，薄雾，写实，360 度全景。
3. 雨夜城市：雨夜未来都市天际线，霓虹广告牌，湿润反光的高架桥远景，低云，蓝紫与红色灯光，赛博写实，360 度全景。
4. 峡谷：巨大红岩峡谷，陡峭崖壁，远处河流，清晨侧光，空气透视，写实，360 度全景。
5. 雪山：夜晚雪山山脊，月光照亮雪面，远处观测站灯光，晴朗星空，写实，360 度全景。
6. 太空港：月面般的灰色陨坑平原，远处圆顶基地和着陆架，黑色星空与地球，写实科幻，360 度全景。
